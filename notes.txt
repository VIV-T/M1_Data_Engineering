Run a script.py inside a container launch by Airflow :
    ### Tips :
        - every modification on the script.py needs to be updated by a docker-compose build of the container of this script (cf. container scrapper with run_scrapper.py)

        - To debug python scripts launched in additional containers, follow these instructions : (VS Code)
            Assuming the Airflow DAG associated has already fail
            1. cmd :
                docker compose down     (remove the actual container - environement cleaning)

            2. cmd : 
                docker ps -a --filter "ancestor={image_name}" --format "table {{.ID}}\t{{.Image}}\t{{.Status}}"
            3. Copy the id of the container returned by the previous cmd as 'container_id'
            4. cmd :
                docker logs -f container_id
            => You will have all the logs you have setted + the python Traceback in case of failure in the terminal.

            5. After debugging your python scripts, you must execute these cmd to apply the modifications and run the DAG again :
                docker compose build 'name_of_the_service'      (ex : scrapper - it contains my python script)
                docker compose up -d    (normal launch of docker)
